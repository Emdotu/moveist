# Project Agent Instructions

Constraints
- Do not rename existing IDs/classes or change current data keys unless explicitly instructed.
- Avoid refactors. Minimal targeted edits only.
- If a change requires adding a new field to stored data, add it in a backward-compatible way (older saved data should still load).
- After changes, app must still run without console errors.
- Update UI + PDF export only where specified.
- Provide a short checklist of what changed and where.
